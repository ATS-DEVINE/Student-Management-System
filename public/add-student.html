Before You Submit

Validation checklist:
  • Name must be at least 2 characters.
  • Email must be in valid format.
  • Course must be selected.
  • Email should be unique.

The submit button sends data to /api/students using a JSON payload. If the backend or DB fails, the exact error will be shown here.

Tip: after adding a student, open View Students to verify the record.
